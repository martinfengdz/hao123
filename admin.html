    帮助说明 · 常见问题

    后台操作常见问题与解答。忘记密码、数据备份还原、检查更新、数据存放等都在这。

    忘记管理密码怎么办？

    在登录窗口点「忘记密码？」链接（网页后台 /admin.html 与飞牛桌面登录窗都有），用重置令牌改密，无需旧密码。令牌二选一：

    • 方式一（环境变量）：在 docker-compose.yaml 的 environment 加一行 QY_RESET_TOKEN=你的令牌，重启容器生效。
    • 方式二（文件令牌）：往数据卷写文件，容器内路径 /app/data/reset-token.txt（宿主机对应 /var/apps/qiyi-nav/shares/qiyi-nav/data/reset-token.txt，即飞牛文件管理器里该应用 data 目录），写入令牌后重启应用。

    然后在登录窗点「忘记密码？」→ 填令牌 + 新密码（≥6 位）→ 提交即可。文件令牌用后会自动删除（用后即焚）；环境变量令牌每次启动都有效，改密后建议移除。

    镜像是 Alpine，进容器用 /bin/sh 而非 /bin/bash。

    默认管理密码是多少？

    出厂默认密码为 admin。首次登录后请尽快通过工具栏「改密码」修改，避免被他人随意进入。

    怎么修改管理密码？

    三种方式：

    • 已知旧密码：后台工具栏「改密码」按钮，填原密码 + 新密码（≥6 位）即可。
    • 已知旧密码·一键改：docker-compose.yaml 的 environment 加 QY_RESET_PASSWORD=新密码，重启生效（需先停旧容器，否则旧哈希被信任会覆盖）。
    • 忘记旧密码：见上方「忘记管理密码怎么办？」，用重置令牌改密。
    升级 / 迁移前怎么备份数据？

    进入后台 →「自建页面」视图（左侧导航设置）→ 底部「数据备份 / 还原」面板：

    • 下载备份：导出全部数据（配置、网址、自建页面、LOGO、图标）为一个 zip。
    • 还原备份：先自动备份当前数据再覆盖，可随时回滚。

    升级或迁移前务必先「下载备份」，防止意外。

    怎样检查 / 更新新版本？

    后台顶部「检查更新」按钮可拉取 GitHub 最新版本。若发现新版本，页面顶部会出现横幅，点「前往更新」跳转下载最新 .fpk，再到飞牛应用中心手动安装升级。

    数据存在哪里？容器重建 / 升级会丢吗？

    所有数据都在数据卷：宿主机 /var/apps/qiyi-nav/shares/qiyi-nav/data ↔ 容器内 /app/data。网址、配置、自建页面、LOGO、图标都存这里，容器重建、升级都不会丢。飞牛升级时会保留旧数据卷（旧密码哈希因此被信任）。

    升级后密码不对 / 配置没生效？

    这是数据保护的正常现象：飞牛升级保留旧数据卷 config.json（含旧密码哈希），若你之前改过密码，默认 admin 就会失效。解决：用「忘记密码」流程或 QY_RESET_PASSWORD 环境变量重置即可。

    若要从零开始，在飞牛应用中心卸载并勾选「清除应用数据」，重装即为全新状态。

    图标不显示 / 异常？

    工具栏提供：

    • 刷新图标：重新抓取全部站点图标（已自动缓存）。
    • 图标自检：查看获取成功率与未获得域名列表。
    • 重抓未获得图标：对未成功的域名再抓一次。
    怎么自定义 LOGO / 页眉页脚 / 问候语？

    后台「外观」按钮：

    • LOGO：前台 / 后台可分别上传不同图，留空用出厂默认。
    • 页眉 / 页脚：自定义 HTML；页脚可整段替换。
    • 全站 CSS：写任意 CSS 微调样式。
    • 问候语：分时段自动问候或自定义单一文案。
    怎么设置默认搜索引擎 / 天气区 / 开幕动画？

    后台「外观」→「首页行为」区块：

    • 默认搜索引擎：百度（出厂默认）/ 必应 / 谷歌 / 360 / 综合(SearXNG)，首页进入自动预选，仍可手动切换。
    • 开幕动画：开关首页进入时的启动遮罩（LOGO + 加载条淡出）；系统开启「减少动态效果」时自动跳过。
    • 天气：出厂默认启用内置天气组件（实时温度 + 城市 + 风力湿度 + 3 天预报，数据源 wttr.in 免密钥），在「天气城市」填城市名（默认广州）即可；也可在「页首天气区代码」粘贴自定义 iframe 天气卡片（和风天气 / 心知天气 / 中国天气网等）优先使用。script 类代码请放进「页眉 HTML」。
    网址的「用户名 / 密码」和免密登录怎么用？

    在后台「网址分类」表格里，点某行「编辑」，在用户名 / 密码列填写该网站的登录账号密码（可空），保存后前台该链接卡片右下角会出现 钥匙按钮：

    • 免密直达：把账号密码拼进网址（http(s)://用户:密码@主机/）自动登录，适合路由器、NAS、监控等支持 HTTP Basic 认证的设备。
    • 打开站点：普通打开；网页表单类登录站可在浏览器中保存密码后自动填充（Ctrl+Shift+L 唤起）。
    • 凭据仅存于本机数据卷，页面不直接展示密码（默认打码，可点眼睛查看 / 复制）。

    前台链接接口不返回密码明文（仅返回「已设置」标记），免密登录页按需单条拉取，适合个人 / 局域网信任环境使用。

    SearXNG 综合搜索怎么配置？

    后台「设置」→ 启用 SearXNG 综合搜索，填实例地址：Docker 综合版默认 http://searxng:8080；独立部署时填实际地址（如 http://192.168.1.10:8081 或公网 https）。可设为版头默认引擎、结果新标签打开。

    自建页面怎么用？

    后台「自建页面」：新建空白页或上传 HTML 文件，访问地址为 /pages/文件名.html（如 /pages/我的笔记.html），并可加入前台「快捷访问」。页面存于数据卷，容器重建不丢。

    访问地址和端口是多少？

    默认服务端口 1315：

    • 前台首页：http://<设备IP>:1315/
    • 后台管理：http://<设备IP>:1315/admin.html

    动态背景（鼠标交互）

    选择前台/后台的鼠标动态背景效果，保存后前台刷新即时生效；可随时切回「关闭」。

    首页行为（搜索引擎 / 开幕动画 / 天气区）

    首页进入时预选该引擎（仍可手动切换）；选「综合」需先在「设置」启用 SearXNG。
    开启后每次进入首页先显示启动遮罩（LOGO + 加载条）再淡出进入；系统「减少动态效果」设置下自动跳过。
    内置天气组件使用免密钥数据源（wttr.in），显示实时温度 + 城市 + 风力湿度 + 3 天预报；默认「广州」，改城市保存后生效（支持中文/拼音/英文城市名）。
    留空 = 使用内置天气组件（按上方「天气城市」渲染温度/风力湿度/3 天预报）。若填入自定义天气卡片 iframe 代码（如中国天气网天气条 i.tianqi.com、和风天气、心知天气等），则优先使用自定义代码。注意：仅 iframe 类嵌入代码可直接生效，script 类请改放进「页眉 HTML」。

    页眉 / 页脚自定义代码（前后台通用）

    「整页页脚 HTML」现已接管整个页脚：在此直接编写/修改整段页脚代码（系统信息、版权、链接等均可改）；留空则用出厂默认页脚。改完点右下「保存」生效，前台即时更新。

    LOGO 设计（前后台通用）

    前台 LOGO 显示在页头与浏览器标签（favicon）；后台 LOGO 显示在登录窗与应用栏。可分别上传不同图；留空（不传）则两处都用出厂默认卡通图。上传后点「保存」即时生效；「恢复默认」可清回出厂图。

    支持 PNG / JPG / GIF / WebP / SVG；建议用正方形、最大边 ≤512px 的图。上传时前端会自动用 canvas 压缩（透明走 PNG，不透明走 JPEG 0.9），防止尺寸错乱。

    搜索快捷项（搜索框下方的链接）

    每项可改文字、配置 URL（含 {q} 时点击会用该项文字替换占位直接打开）；URL 留空则保留旧行为（把文字塞入搜索框走当前引擎）。可增删、上下移。

    建议保留 ≤8 项：项过多会挤占搜索框下方空间，桌面端每行约 6–8 个为宜。天气/新闻/股票/汇率/快递/地图为出厂默认，可自由替换为你的常用站点。
